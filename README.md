# 💙 BlueWave Calculator

## Project Information
**Project Name:** BlueWave Calculator

**Subject:** Object Oriented Programming (OOP)

**Activity:** CIE-2 Activity-6 – OOP GUI Application

**Programming Language:** Java

**GUI Technology:** Java Swing

## 1. Introduction
BlueWave Calculator is a simple and attractive graphical calculator developed using Java Swing.

It helps users perform basic mathematical operations through a user-friendly interface.

The application has a beautiful blue and white colour combination.

## 2. Objectives
- To develop a simple calculator using Java.
- To understand Java Swing components.
- To understand Object-Oriented Programming concepts.
- To perform basic mathematical calculations.
- To learn event handling in Java.

## 3. Features
- Addition
- Subtraction
- Multiplication
- Division
- Clear All button
- Attractive blue-themed interface
- Input validation
- Division by zero handling

## 4. Technologies Used
- Java
- Java Swing
- AWT
- Visual Studio Code
- JDK

## 5. OOP Concepts Used
1. Class – BlueWaveCalculator
2. Object – Created using the constructor.
3. Inheritance – JFrame is extended.
4. Interface – ActionListener is implemented.
5. Event Handling – actionPerformed() handles button clicks.

## 6. How to Run the Project

**Step 1:** Install Java JDK.

**Step 2:** Open the project folder in VS Code.

**Step 3:** Open the terminal.

**Step 4:** Compile the program:

```bash
javac BlueWaveCalculator.java
```

**Step 5:** Run the program:

```bash
java BlueWaveCalculator
```
